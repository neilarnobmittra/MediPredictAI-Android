# MediPredict AI – Android

## Login
- **Email + Password** only (Google Sign-In has been removed)

## Firebase Setup
1. Enable **Email/Password** in Firebase Console → Authentication → Sign-in method
2. Make sure `google-services.json` is in the `app/` folder

## How to run
1. Open project in Android Studio
2. Sync Gradle
3. Run on phone / emulator

## Package name
`com.medipredict.ai`

## Disclaimer
Educational use only. Not a medical diagnosis.
